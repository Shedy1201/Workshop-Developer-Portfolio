# Workshop-Developer-Portfolio
# Mission
    Créez un portfolio de développeur en utilisant uniquement HTML, sans CSS ni JavaScript. 
    Votre page doit présenter votre profil et vos projets de manière claire, logique et accessible. 
  
# Éléments obligatoires 
    1. Une structure HTML complète avec <!DOCTYPE html>, html, head et body.
    2. Un titre de page pertinent et un attribut lang.
    3. Un header avec votre nom et une courte présentation.
    4. Un nav avec des liens internes vers les sections de la page.
    5. Un main contenant :
       ○ Une section About Me.
       ○ Une section Skills.
       ○ Une section Projects.
       ○ Une section Contact.
    6. Une liste de compétences utilisant ul ou ol.
    7. Au moins trois projets présentés avec un titre, une description et un lien.
    8. Une image de profil avec un attribut alt pertinent, si une image est disponible.
    9. Un formulaire de contact contenant au minimum un champ nom, un champ e-mail, un champ message et un bouton d’envoi.
    10.  Un footer contenant une information complémentaire.
      
# Contraintes 
    ● Utilisez des balises sémantiques lorsque cela est pertinent.
    ● Respectez la hiérarchie des titres.
    ● Vérifiez les destinations des liens internes.
    ● Associez les labels aux champs du formulaire.
    ● Indentez proprement votre code.
    ● N’utilisez pas de CSS ou de JavaScript.
  
# Bonus 
    ● Ajouter une section Education.
    ● Ajouter une liste de certifications.
    ● Présenter chaque projet dans un élément article.
    ● Ajouter un lien mailto:.
    ● Ajouter une navigation vers une section supplémentaire.
